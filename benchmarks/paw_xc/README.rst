GPAW PAW-XC / Meinsum experiment
================================

This benchmark measures a 5 x 5 MoS2 monolayer (75 atoms) using PBE,
Gamma point sampling, a 300 eV plane-wave cutoff, float32 wave functions,
and an NVIDIA RTX A4000.  The loose convergence thresholds match GPAW's GPU
profiling example and produce four SCF updates.

The baseline uses GPAW's legacy per-atom NumPy PAW-XC evaluator.  The second
run uses the energy-only NumPy expression in ``gpaw.new.paw_xc_energy`` and
the reverse derivative generated by Meinsum.  GPAW sees both implementations
through the same collective ``(D_asp) -> (e_xc_a, dH_asp)`` interface.

===============================  ===============  ================  =======
Measurement                      Legacy NumPy CPU  Meinsum CUDA AD   Speedup
===============================  ===============  ================  =======
Whole calculation / s                 11.9474           3.9940        2.99 x
PAW-XC total / s                        4.9727           0.4205       11.83 x
PAW-XC per SCF update / ms           1243.17           105.12        11.83 x
PAW-XC fraction / %                    41.62            10.53
Final energy / eV                    -585.326732       -585.339118
===============================  ===============  ================  =======

GPUProfiler records 0.1267 s inside the eight Meinsum device regions (one Mo
and one S shape group for each SCF update), or 31.7 ms of device work per
update.  The difference from the 0.4205 s collective wall time is currently
Python planning, allocation, and host/device transfer.  Caching the two shape
plans and their static setup arrays is therefore the next optimization; it is
not necessary to add more semantics to the energy language.

The 0.0124 eV final-energy difference over 75 atoms is from a deliberately
loose SCF trajectory using float32 and the mathematically consistent automatic
derivative.  Direct evaluation of the energy-only expression matches GPAW's
legacy PBE PAW energy at float64 precision.  A directional finite-difference
test validates the generated Hamiltonian.  GPAW's hand derivative differs by
up to roughly 1.4e-4 relative for the tested Mo setup because its treatment of
the radial origin is not exactly the derivative of the evaluated energy.

Run with::

  .venv/bin/python benchmarks/paw_xc/mos2_gpu_baseline.py \
      --output baseline/mos2-5x5-a4000

Each output directory contains ``baseline-summary.json``, GPAW text output,
and ``gpu-profile.json`` for Chrome tracing or Perfetto.  The measured raw
trace directories are intentionally ignored by Git.
